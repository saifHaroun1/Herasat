# Herasat Security Services Website

A responsive website developed for Herasat Security & Guarding Services using Flutter Web.

The website was built to present the company’s services, mission, and company profile in a modern and simple way while keeping the user experience smooth across different screen sizes.

---

# Features

- Responsive design for desktop and mobile
- Smooth navigation between sections
- Modern landing page UI
- Animated slider section
- About us and mission sections
- Contact information section
- Arabic and English support

---

# Technologies Used

- Flutter Web
- Dart
